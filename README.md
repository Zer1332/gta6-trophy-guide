An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with its sources cited beside it, a roadmap to the platinum, missable-trophy flags, and a checklist that saves in the browser with export/import, kind filters and a spoiler mode that hides story trophies until earned. No network requests at runtime — it runs entirely from its own files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
